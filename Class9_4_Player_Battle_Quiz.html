One-time setup for online multiplayer

  1. Open Firebase Console and create a project.
  2. Open Build → Realtime Database and create a database.
  3. In Project settings, add a Web app and copy its config into FIREBASE_CONFIG near the bottom of this file.
  4. Set up secure database rules/authentication before public use. Do not leave a public database openly writable.
  5. Host this HTML file using GitHub Pages, Netlify, or another HTTPS host; send that same URL to all four players.

If Firebase is not configured, this page will explain that online rooms are unavailable; it will not pretend different devices are connected. Use a private Firebase project and secure it before sharing widely.
